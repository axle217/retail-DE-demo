# Retail Data Engineering Demo

This project is a small end-to-end data engineering pipeline demonstrating how to ingest, transform, and load retail data using Docker, PostgreSQL, and Apache Airflow.

It includes:
- A PostgreSQL database (running via Docker Compose)
- A setup script to initialize the environment (`setup.sh`)
- Airflow DAGs to orchestrate data pipelines
- Artificial retail datasets generated by faker and schemas (OLTP + star schema)

---

## Prerequisites

Make sure you have installed Docker and Docker Compose (v2+)

---

## Getting Started

### 1. Start the environment

Run the setup script from the project root:

```bash
chmod +x setup.sh
./setup.sh
```

The script sets up .env which contains secrets, build Docker environment, and setup the schemas. It is recomended to change username and password in `setup.sh` and secure it if want to develop into production.

### 2. Run the jobs

Generate the raw data:
- Go to Dags -> Look for `generate_oltp_data` -> Trigger

ETL the raw data to star schema:
- Go to Dags -> Look for `load_raw_to_dw` -> Trigger

### NOTE
Not for production, unless passwords are secured.
